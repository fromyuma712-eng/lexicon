# LEXICON

英単語学習アプリ。単一HTMLファイルで動作し、外部依存もサーバ側処理も持たない。学習履歴は `localStorage` に保持する。

公開版: https://lexicon-ecru-one.vercel.app/

## 設計

- **単一ファイル構成** — HTML/CSS/JSを1ファイルに収め、静的ホスティングへ置くだけで動く。ビルド工程を挟まないため、端末を跨いでも同じ挙動になる。
- **間隔反復（SM-2系）** — 正解を重ねた語ほど出題間隔が 3日→約1週→約2週と伸び、忘れかけた頃に再出題される。
- **仕分け不要の運用** — 既知の語は「知っていた」の1操作で即座に除外され、以後は出題されない。学習前に自分で語を選別する手間を要しない。
- **想起練習** — 語義を表示する前に必ず想起の工程を挟む（テスト効果）。進捗はデッキごとに独立して保持する。
- **意匠** — 自作の Android ランチャー「ObservatoryLauncher」の設計言語（OBSERVATORY：鉄紺 #22303C と燠火 #E4572E の 88:12 配分）に揃えている。面は塗らず罫と格点で組み、燠火は「今まさに動いているもの」（計時・現在位置の針・図の最新の一点）にだけ差す。正誤と習熟は色ではなく形と文字で分け、語の分布と読速の推移は軸と目盛りを備えた図で示す。欧文と数字は IBM Plex をラテン文字のみに間引いて同梱している（SIL OFL 1.1・© 2017 IBM Corp.、予約書体名に従い Lexicon Sans / Lexicon Mono と改名）。

## 非公開部分について

私的利用版には上記のほかに高校向けデッキを持つが、当該デッキは市販単語帳を出典とする学習記録から派生したものであるため、公開ビルドから機械的に除去している。除去はビルドスクリプト側で語彙配列と関連UIの双方を対象に行い、公開物には見出し語すら残さない。本リポジトリに含まれるのは除去後の公開ビルドのみである。
